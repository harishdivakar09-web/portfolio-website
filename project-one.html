Project 01 · Physics + AI

NewtonSimAI

A screenshot-to-simulation workflow for freefall and projectile-motion problems, supported by AI-generated questions and feedback.

← All projects

Case study

The goal

NewtonSimAI converts screenshots of freefall and projectile-motion physics problems into situation-specific simulations. Its goal is to help address common misconceptions in introductory physics problems.

How it works

A user uploads a screenshot. An OpenAI API interprets the problem and creates questions. The user answers before and after an adjustable simulation, allowing the system to compare understanding and grade responses.

The experience

The simulation supports changes to height, initial velocity, and angle, as well as time scrubbing, pause and resume, and multiple playback speeds.

My contribution

This was my first coding project. I was responsible for creating the questions and learned how a web app separates the visual frontend from backend calculations and processes, how asynchronous calls connect them, and how OpenAI API calls can generate and grade questions.

The result

The project gave me a starting point for building a functional web application and a foundation I can use when creating future AI tools for applied mathematics.

Reflection

This was the first time I tried coding a project. I was responsible for creating the questions, and through that work I learned how a web application is structured: the frontend handles what the user sees, the backend manages calculations and processes, and asynchronous calls connect the two. I also learned how to use OpenAI API calls to generate questions and grade responses. Although much of the code was initially difficult to follow, the project gave me a practical starting point for understanding how a fully functional web app is built. That foundation will be useful if I create my own AI agent to support future work in applied mathematics.
