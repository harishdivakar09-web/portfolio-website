Project 03 · JacHacks

Flair

An autonomous website auditor that grades UI and UX using the Jac programming language, browser testing, and an LLM.

← All projects

Case study

The goal

Created during the University of Michigan’s JacHacks hackathon, Flair grades a website’s visual appeal, aesthetics, visual clarity, and textual clarity.

Four-day build

My partner and I built the project in four days while learning Jac and using Claude Code and Codex to support development.

How it works

A user enters a website URL. An agent crawls the site while a headless browser tests interface functionality. The collected data is sent as JSON to an LLM, which reports issues, recommendations, and grades. Users can review each section with related screenshots.

The result

The project introduced me to DevOps concepts around testing, deployment, and monitoring. I learned how Jac differs through object-spatial programming and built-in deployment capabilities, and I gained practice reading technical documentation.

View GitHub repositoryDemo video

Reflection

This project took me further into the details of software engineering. I learned about DevOps and how testing, deployment, and monitoring are essential parts of a software application—not tasks that happen only after the coding is finished.

I also learned how the Jac programming language differs from other languages through features such as object-spatial programming and its deployment capabilities. Reading unfamiliar programming documentation was a challenge, but working through it improved my ability to learn a new technical system. I left the hackathon with a functioning project and a clearer understanding of how much software engineering includes beyond simply coding an app.
