Project 02 · Applied mathematics

Urban Pulse

A study using linear algebra to interpret the long-term effects of an urban revitalization policy in Phoenix, Arizona.

← All projects

Case study

The question

How can systems of linear equations, vectors, and matrices help a policymaker understand the long-term effects of an urban revitalization policy?

Academic context

I completed this project while taking a dual-enrollment linear algebra course with a Lawrence Technological University professor.

The approach

Four tasks use linear algebra to add insight into population distribution and the policy’s potential efficacy. I also wrote Python code to verify the mathematics, accept a general 4×4 matrix, and learn the foundations of NumPy.

The result

The study connects eigenvalues and steady-state matrices with a practical urban-planning scenario, combining mathematical work, a reusable computational model, and contextual interpretation.

View GitHub repositoryRead project paper

Reflection

This project was especially interesting to me because it truly felt like doing applied mathematics. I applied my knowledge of linear algebra throughout the four tasks, created a model to double-check my calculations, and made the program flexible enough to accept any general 4×4 matrix. Just as importantly, I interpreted the mathematical results in the context of the urban revitalization policy rather than treating them as isolated numbers.

The project provided an early view of the kind of work I hope to pursue in the future and showed me how mathematics can contribute to an area such as urban planning. I also learned how to use NumPy, a foundational Python package that I expect to use in more advanced data-analysis and machine-learning projects.
